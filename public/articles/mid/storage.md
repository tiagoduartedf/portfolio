# Local Storage vs Session Storage

## Local Storage:
Os dados armazenados no Local Storage persistem mesmo após o navegador ser fechado e reaberto. Eles permanecem no navegador até que sejam explicitamente removidos pelo usuário ou pelo código JavaScript.

## Session Storage:
Os dados armazenados no Session Storage são válidos apenas para a sessão atual do navegador. Isso significa que eles são excluídos automaticamente quando o navegador é fechado. Cada aba ou janela do navegador possui seu próprio sessionStorage, ou seja, os dados armazenados em uma aba não estão disponíveis em outras abas ou janelas.
